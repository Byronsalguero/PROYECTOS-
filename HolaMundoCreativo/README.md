# Hola Mundo Creativo

Primer programa en Visual Basic .NET.

## ¿Qué hace?

Muestra en la consola un saludo creativo y un mensaje de bienvenida.

## Requisitos

- Visual Studio 2022 o .NET 8 SDK.
- Visual Basic .NET.

## Ejecución

Abre `HolaMundoCreativo.vbproj` en Visual Studio y ejecuta con **F5**.
